# Прототип: бот без пользовательского аккаунта

Этап 1 из [rewrite-plan.md](rewrite-plan.md). Проверка проводилась 2026-10-15 на Telethon 1.45.0. Бот работал во временной сессии в памяти и вошёл по токену; пользовательская сессия не использовалась, в канал ничего не отправлялось. С машины разработчика Telegram доступен только через SOCKS5-прокси `127.0.0.1:2080`.

## Что бот может

| Проверка | Результат |
|---|---|
| Найти канал без кэша сессии | ✅ `get_input_entity(-1001100109226)` даёт `InputPeerChannel` с `access_hash=0`, и запросы с ним работают |
| Читать сообщения по id (`channels.getMessages`, 100 id за запрос) | ✅ любые годы, от 2017-11-05 до сегодняшнего дня |
| Узнать последний id | ✅ один запрос: `updates.getChannelDifference` со старым `pts` возвращает `ChannelDifferenceTooLong`, а в нём `dialog.top_message` (на 2026-10-15 это 35868). `read_inbox_max_id` из `GetFullChannel` для этого не подходит: он застрял на 11938 (ноябрь 2023) |
| `GetFullChannel` | ✅ работает |
| `views`, `forwards` | ✅ есть у всех постов всех лет |
| `post_author` | ✅ у новых постов. У постов 2017 года подписей нет, с 2023 года подписи есть у всех |

## Чего бот не может

| Проверка | Результат |
|---|---|
| Реакции | ❌ поле `reactions` пустое у всех просмотренных постов, включая 94 последних, хотя реакции в канале включены (`available_reactions = ChatReactionsSome`). `messages.getMessagesReactions` возвращает `BOT_METHOD_INVALID`. Вывод: через pull-запросы бот реакций не видит. Через push бот получает только изменения реакций (`updateBotMessageReactions`), и только пока запущен, поэтому для старых постов это не поможет |
| Частые запросы | ⚠️ `getMessages`: примерно 4 запроса подряд, затем FloodWait 30 с; в устойчивом режиме около 1 запроса в 7–8 с. Полный обход 36 тыс. id (около 360 запросов) займёт порядка 45 минут |

## Не проверено

- **Пересылка медиа по ссылке** (`send_file(target, [m.media …])`). Бот не может писать в тестовый чат из `.env`: как `PeerChat` получаем `PEER_ID_INVALID`, как `PeerChannel` с `access_hash=0` — `CHANNEL_INVALID`. Похоже, бота в этом чате нет, или чат пересоздан. Значит, текущий тестовый режим `app.py` тоже не работает.

## Попутные факты о канале

- В 2017 году альбомов нет; в 2023-м есть (по 2–8 элементов).
- Репосты бота идут примерно 5–6 раз в день (28 штук за 2026-10-10…15).
- Репосты ноября 2023 подписаны «День в истории», нынешние — «Альцгеймер». Это подтверждает пункт 1 обзора: без фикса этапа 0 старые репосты снова попадали в выборку.
- В истории попадаются стикеры (5 штук на 94 последних сообщения) и превью ссылок (`MessageMediaWebPage`).

## Что из этого следует

1. **Чтение через бота вписывается в лимиты.** Обычному запуску нужно 2–3 запроса: `getChannelDifference`, чтобы узнать последний id; окно с новыми постами для индекса; повторный запрос кандидатов выбранного дня. Первичное построение индекса лучше сделать один раз пользовательским аккаунтом (`iter_messages` быстрый) или медленно ботом (около 45 минут).
2. **Реакций у бота нет.** Нужно выбрать одно из двух:
   - **только бот:** ранжировать по `forwards` и `views`. Эти данные есть у постов всех лет, включая 2017–2021, где реакций не было вообще;
   - **бот и пользователь:** пользовательский аккаунт остаётся, чтобы читать реакции кандидатов при каждом запуске.
3. **Пересылку по ссылке нужно проверить**, как только у бота появится тестовый чат.
