# pupas-lupas-history-bot

Telegram-бот «#MemeThrowback». За один запуск он публикует в канал один старый мем, вышедший в этот же день N лет назад, и завершается. Запуски идут по расписанию раз в несколько часов (расписание живёт вне репозитория).

## Документация

Вся проектная документация лежит в `docs/`. При изменении поведения бота обновляй её в том же коммите.

- [docs/architecture.md](docs/architecture.md) — как бот работает сейчас: алгоритм, конфиг, состояние, деплой.
- [docs/review.md](docs/review.md) — известные баги и проблемы с привязкой к строкам.
- [docs/rewrite-plan.md](docs/rewrite-plan.md) — целевая архитектура и план переписывания по этапам.

## Устройство

- `app.py` — всё в одном файле, работа начинается при импорте. Два клиента Telethon: `user` (пользовательская сессия, читает историю канала и скачивает медиа) и `bot` (публикует).
- `filters.py` — `can_be_reposted` для группы, без побочных эффектов (его можно импортировать в проверках, а `app.py` — нельзя).
- `dateutils.py` — даты; `sorter.py` — ранжирование по реакциям; `message.py` — `GroupedMessages` (альбом или одиночный пост); `supported_media.py` — проверка типа медиа; `memery/` — JSON-список уже опубликованного.
- Конфиг: `.env.defaults` (в git) ← `.env` (секреты, не в git) ← переменные окружения. Список переменных — в `docs/architecture.md`.
- Состояние в `storage/` (в `.gitignore`): `sessions/*.session` и `memery.json`.

## Команды

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py          # ВНИМАНИЕ: реальный вход в аккаунты и публикация
docker compose run --rm bot      # то же самое в контейнере, storage/ монтируется
```

Тестов, линтеров и type-check пока нет. CI ([.github/workflows/build.yml](.github/workflows/build.yml)) только собирает образ и публикует его в GHCR на каждый push в `main`.

## Правила

- **Не запускай `app.py` и не делай вызовы Telegram без явной просьбы.** Код входит в настоящий пользовательский аккаунт и бота и публикует в боевой канал. Даже с `TELEGRAM_TEST_CHAMBER_ID` он пишет в memery и может испортить боевое состояние.
- `storage/sessions/*.session` — это доступ к аккаунтам. Не читай, не печатай и не копируй их; `.env` тоже не выводи. Следи, чтобы `storage/` не попал в git или в Docker-образ.
- Репосты публикуются в тот же канал, откуда берутся мемы. Любая логика выбора должна исключать собственные посты бота (у них подпись `#MemeThrowback`).
- Фильтры и скоринг применяй к группе (альбому), а не к отдельному сообщению.
- Код, комментарии и сообщения коммитов — на английском, документация в `docs/` — на русском.
- Python: локальный `.venv` на 3.12, Dockerfile на 3.10. Не используй синтаксис новее 3.10, пока версии не выровнены.
